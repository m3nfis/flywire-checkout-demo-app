# Translation Flags and Refactoring Suggestions

This file tracks strings from `en.yaml` that are difficult to translate, lack context, or require code changes to support specific languages (e.g., gender, complex plurals, or syntactic differences).

| Key | Language | Issue | Suggestion |
|-----|----------|-------|------------|
| error.declinedTitle | es-ES, es-419 | “Woopsie!” is a joke. A formal usted register cannot carry it. | Use a short restrained line, currently “Pago no completado”. Restore the joke only if the copy can be informal. |
| error.declinedSubtitle | es-ES, es-419 | “Denied!” belongs to the same joke. | Plain “Rechazado”, without the exclamation. |
| demo.split.amountPlaceholderCents | es-ES, fr-FR, fr-CA, de, it, pl | These locales write decimals with a comma (“0,00”). The split amount field is `<input type="number" step="0.01">`, so the value itself uses a dot. The placeholder is only a hint. | Keep “0,00” as the hint, or switch the field to text and parse both comma and dot if guests should type a comma. |
| stay.weekdaySu | pt-PT, pt-BR | Standard two-letter weekday abbreviations collide (Se/Qu/S). The Sunday-first grid needs a unique label for each day. | Current set: Do, Sg, Te, Qa, Qi, Sx, and Sá (pt-PT) or Sb (pt-BR). Standard letters, or a Monday start, need a per-locale first weekday in the calendar code. |
| stay.night_one | pt-PT, pt-BR | Portuguese treats 0 and 1 as the same plural category, so a count of 0 uses the singular (“0 noite”). Same for nightShort, child, extraGuest, booking, and activity.events. | Leave it, or add a `_zero` form such as “sem noites” if the UI can show 0. |
| error.declinedTitle | pt-PT, pt-BR | “Woopsie!” and “Denied!” do not fit a formal register. The “universe” line was dropped. | Current pair: “Pagamento recusado” / “Não autorizado”. A lighter option is “Ups!” (pt-PT) or “Ops!” (pt-BR) if the joke should stay. |
| demo.hideAmountHelp | all | The English ends with “Shown by default.” It is unclear whether that means the amount or the toggle. | Change the English to “The amount is shown by default.” and align every locale. |
| server.missingCredentials | all | The demo server still returns the English `server.*` sentences. These translations are ready, but they do not appear until the server sends a code or the locale. | Return an error code and map it in the browser, or pass the locale to the server. |
| dashboard.cleanedField | pt-PT, pt-BR, fr-FR, fr-CA | The “{fixes}” list is grammatical only if `dashboard.fix.*` stays a bare noun phrase, including when several fixes are joined. French otherwise needs articles and elision (“de espaces”). | Keep every locale’s fix fragments as article-free nouns. |
| stay.night_one | fr-FR, fr-CA | French treats 0 and 1 as the same plural category, so a count of 0 uses the singular (“0 nuit”). Same for the other `_one` keys. | Leave it. French accepts “0 nuit”. Add `_zero` only if a count of 0 should read differently. |
| stay.removeGuests | fr-FR, fr-CA | The label is “Réduire le nombre d’{who}”. The elision is correct only because `adultsLower` and `childrenLower` both start with a vowel (“adultes”, “enfants”). | Keep those two words vowel-initial, or stop inserting `{who}` and use two full sentences. |
| common.guest | fr-FR, fr-CA | The nameless fallback “Voyageur” is masculine, so a greeting can misgender the guest. | Use a neutral fallback, or drop the noun and say only “Bienvenue”. |
| rooms.heroAlt | fr-FR, fr-CA | “Aegean” and “caldera” stay in Latin script, so French reads “l’Aegean” and “la caldera” instead of “la mer Égée” and “la caldeira”. | Keep the names if the brand rule stands. Otherwise allow the French geographic words. |
| activity.status.completed | fr-FR, fr-CA | Status pills are masculine (“Terminé”, “Refusé”) as if the subject is Checkout. A feminine subject such as “réservation” would need “Terminée”. | Confirm the subject of each pill and keep one gender per set. |
| error.declinedTitle | fr-FR, fr-CA | “Woopsie!” and “Denied!” do not fit formal vouvoiement. The universe line was replaced. | Current pair: “Paiement non abouti” / “Refusé”. |
| error.declinedTitle | de | “Woopsie!” and “Denied!” do not fit the Sie register. | Current pair: “Leider nicht möglich” / “Abgelehnt”. |
| error.declinedTitle | it | “Woopsie!” and “Denied!” do not fit the Lei register. | Current pair: “Operazione non riuscita” / “Rifiutato”. |
| stay.removeGuests | it | Short actions use the infinitive (“Rimuovere {who}”) so they stay clearly Lei rather than tu. Without an article this is telegraphic (“Rimuovere adulti”). | Switch button labels to the Lei imperative (“Rimuova {who}”) if that should be consistent everywhere. |
| flows.reserve_hold.guestTitle | de, it | “Hold” became “Vorautorisierung” / “preautorizzazione”, so the guest title is much longer than “Reserve & Hold” and may overflow a card. | Shorten the guest title only if the card is too narrow. Keep the longer word in staff copy, where precision matters. |
| error.declinedTitle | pl | “Woopsie!” and “Denied!” do not fit a formal register. The universe line was softened. | Current pair: “Przykro nam” / “Płatność odrzucona”. |
| success.cardSavedIfChosen | pl | “If you chose” needs a gendered past tense (wybrał / wybrała) or Pan/Pani. Same pressure on “what awaits you”, “so you can be present”, and “we held your suite”. | Kept impersonal: “jeśli wybrano tę opcję”, “Co czeka na miejscu”, “aby można było”. Use “Państwo” only if that address is wanted. |
| rooms.heroAlt | pl | “Aegean” and “Caldera” cannot take Polish case endings, so they sit next to a Polish noun (“morze Aegean”, “zatoka Caldera”) instead of “Morze Egejskie” and “kaldera”. | Keep the English names, or allow the Polish geographic words where the name is not the brand. |
| stay.guestTitle_other | pl | `_other` is the fractional form (“2,5 gościa”, “1,5 rezerwacji dokonanej”). It is grammatical and unused, because guest counts are whole numbers. | Leave the forms. They only appear if a count is not an integer. |
| booking.couldNotStart | pl | “Checkout” stays uninflected as a product name (“uruchomić Checkout”). Natural Polish would inflect it (checkoutu). | Keep it uninflected, or switch every staff string to the inflected lowercase form. |
| error.declinedTitle | ja, ko | “Woopsie!”, “Denied!”, and the “universe” line do not fit a formal register. | Japanese: “申し訳ございません” / “お支払いが承認されませんでした”. Korean: “죄송합니다” / “결제가 승인되지 않았습니다”. |
| stay.nightTitle_one | ja, ko, zh, vi, id | There is no title case, and plural rules only return “other”, so the title and plain forms are the same string. | Leave them identical. |
| guest.firstName | ja, ko, zh, vi | The form and `app.js` build the name as first name, then last name. These languages expect the family name first. | Compose the name per locale, or greet with the family name only. Indonesian keeps given name first. |
| common.and | ja, zh, id | Lists are joined in code with a Latin comma plus the word for “and”. Japanese and Chinese need “、” and no extra spaces. Indonesian “A, B dan C” drops the comma that “A, B, dan C” uses in `credentials.allMissing`. | Use `Intl.ListFormat` for the locale instead of a hardcoded joiner. |
| error.declinedTitle | zh, vi, id | “Woopsie!”, “Denied!”, and the “universe” line do not fit a formal register. | Chinese “很抱歉”. Vietnamese “Rất tiếc”. Indonesian “Mohon maaf”. Each is followed by a plain request to try another card. |
| dashboard.timeAgo | zh, vi, id | After 24 hours the back office formats the date with `toLocaleDateString('en-GB')`, ignoring the page language. Amounts in the same file use `en-US`, and checkout activity clocks use `en-GB`. | Pass `I18n.locale` into those formatters. |
| credentials.fields.client_id | vi | “ID khách hàng” is the usual business term, but “khách” is also the word for a hotel guest, so it can be read as the guest’s id. | Keep “ID khách hàng”, or leave “Client ID” in English if the two must not be confused. |
| success.cardSaved | ja | The required leading space is appended after a sentence that already ends with “。”, so a gap appears. Same for the other card-saved notes and `dashboard.savedInBrowser`. | Put the separator in code, and drop the leading space from these Japanese strings. |
| common.guest | ja, ko | The fallback “お客様” / “고객” is a title, not a name. If it is ever passed into “{name}様” or “{name} 고객님”, the honorific is doubled. | Keep the fallback out of templates that already include 様 or 고객님. |
| flows.reserve_hold.guestTitle | ja | “Hold” is “与信確保”, which is accurate and more technical than a guest expects. | Use “カードの仮押さえ” on guest titles if the card should sound less like a bank. |
