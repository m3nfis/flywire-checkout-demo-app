Minimal client guide

Integrate Flywire Checkout V2 with anonymous sessions

Anonymous sessions let a frontend-only page start Flywire Checkout in order to complete a payment.

Start the steps Copy the example

The short version

  1. Load connect.js.
  2. Call window.cpx_core.start.
  3. Handle on_end and on_error.

Use anonymous sessions for simple payments

Use anonymous sessions when you want to add a simple payment checkout to your page with a lightweight frontend-only integration.

If you need more capabilities, such as an event system, stronger security, status follow-up, or a more tailored payment flow, contact Flywire. We will guide you to the right session setup.

Step by step

How to integrate

1

Get your integration values

Flywire provides two environments. Use the correct gateway origin when loading the checkout runtime:

  • Demo — https://checkout.demo.flywire.com
    Script: https://checkout.demo.flywire.com/gateway/connect.js
  • Production — https://checkout.flywire.com
    Script: https://checkout.flywire.com/gateway/connect.js

You also need:

  • YOUR_CLIENT_ID — your client identifier (provided by Flywire).
  • YOUR_RECIPIENT_CODE — the recipient configuration checkout should use.
2

Load the Flywire Checkout browser runtime

Add the connector script on the page where checkout starts. Use the URL matching your environment:

<script src="https://checkout.demo.flywire.com/gateway/connect.js" defer></script>
<script src="https://checkout.flywire.com/gateway/connect.js" defer></script>
3

Start checkout without a session object

window.cpx_core.start({
  recipient: {
    client_id: "YOUR_CLIENT_ID",
    code: "YOUR_RECIPIENT_CODE"
  },
  transaction: {
    type: "payment",
    details: {
      amount: "123.45"
    }
  },
  response: {
    on_end: function (reason, payload) {
      console.log("Checkout ended:", reason, payload);
    },
    on_error: function (type, payload) {
      console.error("Checkout error:", type, payload);
    }
  }
});
4

Handle the result in the browser

on_end is called when checkout completes or is canceled. For anonymous sessions, a completed checkout can include a high-level session status and payment report. 

{
  status: "COMPLETED",
  paymentReport: {
    status: "FULLY_PAID",
    amount: "123.45",
    currency: "USD",
    paymentWatchlist: []
  }
}
5

Test the main paths

Before going live, test a completed payment, a canceled checkout, and an error case. Show clear messages for each one.

Copy-paste starter

Minimal anonymous checkout page

This example starts a payment checkout from a button. Replace the placeholder values before testing. 

<button id="start-cpx-checkout" type="button">Pay now</button>
<p id="cpx-result" role="status"></p>

<!-- Demo: https://checkout.demo.flywire.com/gateway/connect.js -->
<!-- Prod: https://checkout.flywire.com/gateway/connect.js      -->
<script src="https://checkout.demo.flywire.com/gateway/connect.js" defer></script>
<script>
  function showResult(message) {
    document.getElementById("cpx-result").textContent = message;
  }

  function startCheckout() {
    if (!window.cpx_core) {
      showResult("Checkout is still loading. Please try again.");
      return;
    }

    window.cpx_core.start({
      recipient: {
        client_id: "YOUR_CLIENT_ID",
        code: "YOUR_RECIPIENT_CODE"
      },
      transaction: {
        type: "payment",
        details: {
          amount: "123.45"
        }
      },
      response: {
        on_end: function (reason, payload) {
          if (reason === "completed") {
            showResult("Checkout completed.");
            console.log("Payment report:", payload);
          } else {
            showResult("Checkout was canceled.");
          }
        },
        on_error: function (type, payload) {
          showResult("Checkout could not start or finish.");
          console.error("Checkout error:", type, payload);
        }
      }
    });
  }

  document
    .getElementById("start-cpx-checkout")
    .addEventListener("click", startCheckout);
</script>

Before sharing with users

Final checklist

  • Use the Flywire-provided gateway origin, client id, and recipient code.
  • Load connect.js from the correct environment (checkout.demo.flywire.com or checkout.flywire.com) before starting checkout.
  • Handle completed and canceled in on_end.
  • Handle on_error and show a recoverable message to the payer.
  • Contact Flywire if you need events, stronger security, status follow-up, or a more tailored payment flow.
